## 3. 生成的资产

| 资产 | 用途 |
|---|---|
| `D225_Item_Flashlight` / `_Fuse` / `_StairKey` | 手电、保险丝、门禁钥匙 |
| `D225_Clue_DormNote` / `_Bulletin` / `_ShiftLog` | 桌面便笺、公告栏、值班记录 |
| `D225_Puzzle_FuseBox` | 配电箱（T07） |
| `D225_Puzzle_StairDoor` | 二楼楼梯门禁（T08） |
| `D225_Puzzle_ExitSwitch` | 门厅出口联动装置（T11） |
| `D225_Trigger_Evacuation` | 楼外出口安全区（T11） |
| `D225_Hiding_Locker` | 储物柜躲藏点（T06） |
| `D225_QuestController` | `QuestLogProvider` + `PuzzleObjectiveTracker`，可直接拖入场景 |

重新生成：

- 菜单 `D225/生成交互与谜题资源`；
- 命令行 `Unity.exe -batchmode -projectPath . -executeMethod D225.Interact.Editor.D225PuzzleAssetBuilder.BuildAll -quit`。

生成器可重复执行，已存在的 ItemData 会复用资产（GUID 稳定），Prefab 覆盖生成。
