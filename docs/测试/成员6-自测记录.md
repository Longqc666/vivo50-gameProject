## 6. 手工验收清单（自动化未覆盖，需在有画面的环境执行）

### T10 暂停与场景

1. 打开 `Assets/Scenes/Scene_Boot.unity` 按 Play → 出现主菜单；
2. 点「开始游戏」→ 淡出 → 进入 A 区 `Scene_A_Dorm`，角色站在 `CP_A_Spawn`（x≈1.2）；
3. 按 `A/D` 能走、按 `Esc` 暂停：角色停住、再次 `Esc` 恢复；
4. 往回走再往前，暂停前后位置不跳变。

### T09 检查点失败

1. 在 A 区走到 `CP_A_Door`（x≈8.2）→ Console 出现「通过检查点 CP_A_Door」；
2. 控制台无法直接「被抓」，可在 Editor 的 `GameManager` 上手动触发，或等成员2 的 AI 接入后：
   `NotifyPlayerCaught("manual")` → 出现失败页；
3. 点「从检查点重试」→ 场景重载、角色回到 `CP_A_Door`、已拾取的道具仍在背包、`PuzzleFlag` 不丢；
4. 暂停状态下不应进入失败页（`NotifyPlayerCaught` 返回 false 并在 Console 写忽略原因）。

### T11 / 结算

1. B 区未开楼梯门时走到 x≥28.3：Console 提示「楼梯门还锁着」，不切场景；
2. 写入 `StairDoorUnlocked` 后再走到 x≥28.3：切到 C 区，出生点 `CP_C_Entry`；
3. C 区走进 `EvacuationZone` 并写入 `EvacuationComplete` → 出现结算页「撤离成功」。

### T12 Windows 构建

1. 运行 `D225/流程/9. 构建 Windows 版`；
2. 双击 `Build/Windows/D225.exe`：从主菜单进入 A 区，能暂停/继续/退出；
3. 记录机器（非开发机）、是否缺资源、是否可退出。
